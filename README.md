# Verdigris Isles — Tropical Island Theme

A GitHub Pages-ready Verdigris Isles homepage redesigned around the supplied island reference image.

## Visual direction
- Bright turquoise/teal water
- Highly visible white surf and foam
- Warm sandy beaches
- Jungle-green vegetation and rocky cliffs
- Rounded, organic cards and buttons
- Illustrated island-adventure feel
- Coastal field-guide atmosphere
- Subtle magitech/fantasy styling

## Files
- `index.html`
- `assets/island-reference.jpg`

The supplied image is stored locally so the page does not depend on an external image host.

## GitHub Pages
Upload the contents of this folder to a repository, then enable **Settings → Pages → Deploy from a branch → main → / (root)**.
